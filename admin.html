Free News Manager

ध्यान दें: यह 100% free, browser-based manager है। इसमें खबरें आपके device/browser में सुरक्षित रहती हैं। Live website पर automatically publish करने के लिए GitHub में news.json update करना होगा।

1. नई खबर बनाएं

2. Backup / Restore

3. GitHub publish

Backup डाउनलोड करें, फिर GitHub में news.json की contents replace करके Commit changes करें। Website नया data दिखाएगी।

Security: GitHub token/password इस page में कभी नहीं डालना है.
